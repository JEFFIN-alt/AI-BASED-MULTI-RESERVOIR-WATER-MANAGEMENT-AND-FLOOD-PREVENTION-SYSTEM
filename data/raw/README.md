# Raw Directory

## Purpose
Raw, unmodified datasets collected from sensors, agencies, or scraping scripts.

## Details
Contains all original data source folders. These files must serve as the single source of truth and must never be modified directly.

## Metadata
- **Type**: Raw Data (Read-Only)
- **Expected Formats**: .csv, .parquet, .npy
- **Maintenance**: DO NOT EDIT OR MODIFY FILES IN THIS DIRECTORY DIRECTLY.
