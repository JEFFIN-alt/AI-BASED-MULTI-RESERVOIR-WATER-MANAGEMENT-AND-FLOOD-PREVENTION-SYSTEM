# KSEB Directory

## Purpose
Raw data from Kerala State Electricity Board power generation reservoirs.

## Details
Water release logbooks, turbine discharges, and spillway statuses for hydro-power reservoirs.

## Metadata
- **Type**: Raw Data (Read-Only)
- **Expected Formats**: .csv, .parquet, .npy
- **Maintenance**: DO NOT EDIT OR MODIFY FILES IN THIS DIRECTORY DIRECTLY.
